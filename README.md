# Student Data Processing and Summary Statistics Using Python

## Objective
To collect, organize, validate, and process student records using Python and generate useful summary statistics.

## Technologies Used
- Python
- Jupyter Notebook

## Concepts Used
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements
- List Comprehension
- Data Validation
- Summary Statistics

## Project Description
This project processes student records containing student names and marks. It validates the marks, determines pass or fail status, and calculates total marks, average marks, highest marks, and lowest marks. It also identifies the highest- and lowest-scoring students and counts the number of students who passed and failed.

## Key Features
- Stores structured student records using a list of dictionaries.
- Validates marks within the range of 0 to 100.
- Calculates total and average marks.
- Identifies the highest and lowest marks.
- Displays individual student results.
- Counts passed and failed students.
- Generates a formatted summary report.

## Expected Results
- Total Students: 5

- Lowest Marks: 78 (Jagdish)

- Students Failed: 0

## Conclusion
This project demonstrates how Python can be used to process structured data, perform calculations, validate records, and generate meaningful summaries efficiently.
